# Inline Gutter Annotations

Attach discussions, architectural notes, and todos directly to specific lines of code without polluting your git tree.

### Adding a Note
1. Place your cursor on any line in your editor.
2. Press `Alt+N` (`Cmd+Option+N` on macOS) or right-click and select **git-notes: Add Note**.
3. Type your note markdown message.

[Add Note to Current Line](command:git-notes.add)

Your note is immediately saved to `refs/notes/*` and marked with an inline gutter bullet 💬!
