# Thread Discussions & Reviews

Collaborate asynchronously on complex code reviews with full markdown discussion threads.

### Viewing & Replying to Threads
- Hover over any line with a 💬 icon to view summary tooltips.
- Press `Alt+Shift+N` (`Cmd+Option+Shift+N` on macOS) to open the interactive discussion webview panel.
- Submit replies, track approvals, or resolve discussions with one click.

[Open Discussion Thread](command:git-notes.showPanel)
